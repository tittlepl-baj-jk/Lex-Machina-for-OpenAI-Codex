# Bezpieczeństwo

## Zakres

Zgłoszenia bezpieczeństwa mogą dotyczyć między innymi:

- przypadkowego ujawnienia kluczy, tokenów lub danych osobowych;
- niezamierzonego wysyłania treści do zewnętrznych API;
- obejścia lokalnej anonimizacji;
- wykonania poleceń repozytorium bez świadomej zgody użytkownika;
- podatności w adapterach lub skryptach portu.

## Zgłaszanie

Po utworzeniu publicznego repozytorium użyj prywatnego zgłoszenia przez GitHub
Security Advisories. Nie umieszczaj sekretów, akt spraw ani danych osobowych
w publicznym Issue.

Jeżeli prywatny kanał nie jest jeszcze skonfigurowany, zgłoszenie powinno
zawierać wyłącznie bezpieczny opis problemu, bez danych pozwalających na jego
wykorzystanie i bez materiałów prawdziwej sprawy.

## Granice odpowiedzialności

Projekt nie gwarantuje poufności danych przekazanych do zewnętrznych usług.
Użytkownik powinien sprawdzić konfigurację dostawców, retencję danych i zakres
wysyłanych informacji przed włączeniem jakiejkolwiek integracji sieciowej.
